# dotfiles

## Apps do you need install before configure this `dotfiles`

- `clipse` -> Clipboard manager
- `impala` -> Wifi manager
- `btop` -> Process manager
- `bluetui` -> Bluetooth manager
- `wiremix` -> Audio manager
- `waybar` -> Docking bar
- `wofi` -> Search apps
- `tmux` -> Terminal multiplexer
- `kitty` -> Terminal
- `zsh` -> Shell and command-line interpreter
- `google-chrome-stable` -> Browser
- `neovim` -> Terminal editor
- `git` -> Version manager
- `go` -> Programming Language
- `volta` or `nvm` -> Node version manager
- `bun` -> Package manager
- `git` -> Version manager
- `obsidian` -> Note-taking application
- `local-send` -> Send files to devices like a phone or table
- `hyprpaper` -> Screen wallpaper
- `hyprlock` -> Screen locker
- `nautilus` -> Files manager
- `docker` -> Container manager
- `lazydocker` -> Terminal interface for Docker
- `lazygit` -> Terminal interface for Git
- `hyprshot` -> Create screen shots
